# ケアプラン文例集 1000 — サポート／プライバシーポリシー

iOS アプリ「ケアプラン文例集 1000」（CHERRY BLOSSOM）の公開ページ。

- https://yuta0032.github.io/bunrei-support/ — 入口
- https://yuta0032.github.io/bunrei-support/support.html — サポート
- https://yuta0032.github.io/bunrei-support/privacy.html — プライバシーポリシー

App Store Connect の `privacyPolicyUrl` と `supportUrl`、および AdMob の
UMP（GDPR メッセージ）の「プライバシー ポリシー URL」に privacy.html を入れている。

書き方の決まり
- 「無料」「お試し」「体験版」の語を書かない（App Store 2.3.7）。
- 広告は Google AdMob、ATT で許可されたときだけパーソナライズ。
- 文例は CHERRY BLOSSOM が作成したもの、と明記する。
